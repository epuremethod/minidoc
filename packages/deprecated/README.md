# @epure/minidoc

Renamed to [`@minidoc/core`](https://www.npmjs.com/package/@minidoc/core).
This package re-exports it, so existing code keeps working, and it is
deprecated.

```sh
pnpm remove @epure/minidoc
pnpm add -D @minidoc/core
```

Then import from `@minidoc/core`. Documentation:
[minidoc.dev](https://minidoc.dev).
