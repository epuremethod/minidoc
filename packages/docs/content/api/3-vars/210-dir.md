---
name: dir
slug: dir
kind: var kind
summary: Render every file of a folder through one template, and join them.
lang: yaml
signature: |-
  name:
    dir: path
    each: "…{{`body`}}…"  # optional
    glob: "*.md"          # optional
    order: asc | desc     # optional
    join: "\n"            # optional
    transform: md         # optional
    optional: true        # optional
---

#### Fields

| Field | Default | Meaning |
| --- | --- | --- |
| `dir` | required | The folder, relative to the declaring layer. |
| `each` | ``{{`body`}}`` | The template of one item. |
| `glob` | `*.md` | Which files. A glob with a `/` reaches into subfolders. |
| `order` | `asc` | `desc` reverses the order. |
| `join` | a newline | What sits between items. |
| `transform` | from each extension | The [transform](#transform) of every file. |
| `optional` | `false` | An empty match, or a missing folder, renders nothing. |

#### What `each` sees

| Name | Value |
| --- | --- |
| frontmatter names | the item's own [frontmatter](#frontmatter) |
| ``{{`body`}}`` | the item's rendered content |
| ``{{`file.name`}}`` | its file name: `01-intro.md` |
| ``{{`file.stem`}}`` | without the extension: `01-intro` |
| ``{{`file.dir`}}`` | the name of its parent folder |

#### Behavior

- Files are ordered by path. Prefix names (`01-`, `02-`) to choose the order;
  `order: desc` puts date-prefixed files newest first.
- `*/x.md` matches one level down, `**/x.md` at any depth.
- An item's frontmatter stays in that item. It is not exported, unlike a
  [`file`](#file) var's.
- An empty match is an error, unless `optional: true`.
- With `inlineErrors`, a failing item renders as an error box and the others
  render.

#### Example

```yaml
var:
  toc:
    dir: guide
    each: '<li><a href="#{{`slug`}}">{{`title`}}</a></li>'
  chapters:
    dir: guide
    each: '<section id="{{`slug`}}">{{`body`}}</section>'
```

Guide: [A folder of chapters](./index.html#a-folder-of-chapters).
