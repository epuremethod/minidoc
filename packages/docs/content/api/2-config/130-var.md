---
name: var
slug: var
kind: config key
summary: A map of templates. Groups nest, and layers merge leaf by leaf.
lang: yaml
signature: |-
  var:
    name: template           # a template
    group:
      key: template          # {{`group.key`}}
    group.key: template      # the same leaf, written flat
    name:
      file: path             # a var kind: file, dir, dirs, list or value
---

#### Where vars are declared

| Layer | Where | Order |
| --- | --- | --- |
| base | the `var` of a `base` config | first, least local |
| config | the config's `var` | second |
| build | a build entry's `var` | third |
| frontmatter | a content file, a page, a `dirs` item | last, most local |

Each layer is merged over the one before it. The later layer wins.

#### Values

- A string is a template.
- Numbers and booleans are templates of their text.
- A list of scalars is data, read by a [`list`](#list) var.
- A map is a group, or a var kind when it holds one of the keys `file`, `dir`,
  `dirs`, `list` or `value`.

#### Behavior

- Groups merge leaf by leaf: a later layer replaces one key and keeps the
  others, even inside a var kind (`layouts.cv.file`).
- A dotted key and a nested key are the same leaf. Defining one leaf twice in
  one layer is an error.
- Whether a group is a var kind is decided after all layers have merged.
- Reading a plain group whole is an error.

#### Example

```yaml
var:
  site: marmot
  colors:
    accent: "#0d7797"
  layouts.cv:
    file: layouts/cv.html
```
