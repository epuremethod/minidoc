---
name: run
slug: run
kind: function
summary: Find the entry configs and build every output they declare.
lang: ts
signature: |-
  function run(options: RunOptions): Promise<void>

  type RunOptions = {
    glob: string
    fs?: FileSystem
    transform?: Record<string, Transform>
    inlineErrors?: boolean
  }
---

#### Options

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `glob` | `string` | required | Selects the entry configs, relative to the filesystem's root. |
| `fs` | [`FileSystem`](#file-system) | `nodeFs()` | Where everything is read and written. |
| `transform` | `Record<string, Transform>` | `{}` | Named [transforms](#transform), added to `md` and `none` or replacing them. |
| `inlineErrors` | `boolean` | `false` | Render content errors in the page instead of stopping. See [errors](#errors). |

#### Behavior

- Every config the glob matches is built, concurrently. A config used only as
  a `base` should not match the glob.
- Every output path is resolved before the first file is written. Two outputs
  on one path stop the build. See [output](#output).
- Outputs are written in place; nothing is deleted first.
- Without `fs`, the Node filesystem is loaded on first use, rooted at the
  current directory. Importing minidoc in a browser stays safe.
- The promise rejects with the first error, unless `inlineErrors` is on and the
  error is a content error.

#### Example

```js
import { run } from "@epure/minidoc"
import { typescript } from "./highlight.mjs"

await run({
  glob: "content/**/config.yaml",
  transform: { typescript },
})
```
