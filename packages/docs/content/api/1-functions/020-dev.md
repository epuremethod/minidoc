name: dev
slug: dev
kind: function
summary: Build, watch, rebuild on change and serve the output with live reload.
lang: ts
signature: |-
  function dev(options: DevOptions): Promise<Server>

  type DevOptions = WatchOptions & {
    serve?: string
    port?: number
  }
---

#### Options

Every option of [`watch`](#watch), plus:

| Option | Type | Default | Meaning |
| --- | --- | --- | --- |
| `serve` | `string` | `"dist"` | The folder served, relative to `root`. |
| `port` | `number` | remembered | A fixed port. Skips the remembered port and writes nothing. |

#### Behavior

- Builds once, then rebuilds as [`watch`](#watch) does.
- Serves `serve` as static files. `/guide/` answers with its `index.html`;
  `/guide` with `guide.html`, then `guide/index.html`.
- Each served HTML page gets one injected line: an `EventSource` that reloads
  the page when a build lands.
- Requests outside the served folder answer `403`.

#### The port

- Without `port`, the port is read from `var: port:` of the entry config.
- On first launch there is none: a free port is drawn and written there. The
  config is rewritten through yaml's document API; comments and layout stay.
- The remembered port is never replaced. When a minidoc dev server already
  answers on it, `dev` prints its address and returns. When anything else
  holds it, `dev` fails.

#### Returns

A [`Server`](#watcher): `port`, and `stop()` to stop watching and serving.

#### Example

```js
import { dev } from "@epure/minidoc"

await dev({
  glob: "content/**/config.yaml",
  build: "src/build.mjs",
  watch: ["../shared"],
})
```
